# Igbo USAS Tagset

The USAS tagset in Igbo can be found in `docx` and `pdf` formats from [USASSemanticTagset - Igbo.docx](./USASSemanticTagset%20-%20Igbo.docx) and [USASSemanticTagset - Igbo.pdf](./USASSemanticTagset%20-%20Igbo.pdf) respectively.

A less formatted (not in table format) but identical content of the docx can be generated using the following python script; `python tagset_to_docx.py` of which this generates the following docx file `USAS_Igbo_Translation.docx`.
